# SciStarter (SCloud-Kickstarter)

Платформа для поддержки и заказа научных исследований - "наука с вашим участием".

Проект объединяет три роли:

- Заказчик формулирует задачу, согласует предложение команды и принимает этапы.
- Спонсор поддерживает опубликованные исследования и следит за результатами.
- Научная команда публикует проекты, получает запросы и сдаёт отчёты по этапам.

Уже реализовано:
- Система регистрации
- Система поиска через AI
- Система отзывов
- Система сдачи отчёта поэтапно
- Система публикаций своих исследований
- Система поддержки (спонсорства)
- Фильтр по проектам на главной странице
- Личные кабинеты под каждую роль (Заказчик, Спонсор, Научная организация)

## Возможности

- Регистрация и вход с выбором роли: заказчик, спонсор, научная команда
- Автоматический вход после регистрации
- Сессионная авторизация и CSRF-защита
- Каталог исследований с поиском, фильтрацией по категориям и сортировкой
- Карточки проектов с прогрессом сбора, командой и статусом
- Страница проекта: описание, гипотеза, методика, риски, этапы, обновления и команда
- Поддержка проектов спонсорами через демо-платёж
- Система достижений и званий в кабинете спонсора
- Создание и редактирование черновиков исследований научной командой
- Публикация проектов в каталоге
- Многоэтапные проекты с бюджетами и сроками
- Заказ исследования заказчиком прямо со страницы команды или проекта
- Входящие запросы в кабинете исследователя
- Подготовка многоэтапного предложения командой
- Просмотр предложений заказчиком и согласование с созданием заказа
- Заказы с этапами, статусами и бюджетами
- Сдача отчётов по этапам научной командой
- Приёмка этапа или возврат на доработку заказчиком
- Автоматический переход к следующему этапу после приёмки
- Завершение заказа после приёмки всех этапов
- Отзывы после приёмки первого этапа
- Отзывы организации на её публичной странице
- Кабинеты со статистикой для заказчика, спонсора и исследователя
- Редактирование профиля организации владельцем
- Просмотр участников, проектов и отзывов организации

## Запуск

### Backend

Нужен запущенный PostgreSQL и база `kickstarter`.

```bash
DATABASE_PASSWORD=kickstarter \
DEMO_PAYMENTS=true \
./gradlew bootRun
```

По умолчанию backend доступен на `http://127.0.0.1:8080`.

### Frontend

```bash
cd frontend
bun install
bun dev
```

Frontend проксирует `/api` на backend.

### Проверки frontend

```bash
cd frontend
bun run lint
bun run build
```
